This directory is for a driving/racing game where players bring their own 3d models of vehicles, which are overlaid onto "standard" platforms. The platforms/racing types should be in control of the performance and other driving characteristics of the vehicles. This should be compatible across Linux, Windows and MacOS.

You can use git to interact with the github repository.
