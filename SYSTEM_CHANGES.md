Not system changes:
- git `user.name` and `user.email` are set in this repo's `.git/config`, not globally.
- Godot runs in self-contained mode, so it does not create `~/.config/godot`, `~/.local/share/godot` or `~/.cache/godot`.
- pip ran with `--no-cache-dir`, so there is no `~/.cache/pip` entry from this project.
- The Windows build was tested under Wine with a throwaway prefix in a temporary folder (not `~/.wine`), with menu-entry creation turned off (M1, M2, M3 and M5).
- M3's multi-monitor runs opened fullscreen windows on both monitors only while the game ran; no display settings were changed.
- M4's screen-reader checks (`tools/a11y_check.py`) run the game in a private D-Bus session with the accessibility bus switched on in memory; the desktop's accessibility settings were not changed. They pass `--no-save`, so no settings or profiles are written.
- M6's editor screenshots and test drives opened windows (one fullscreen on the second monitor) only while they ran.
- M8's export check (the exported dedicated server running a kart race and a battle, with exported Linux bots and the Windows export as a bot) ran the Windows export under Wine in a throwaway prefix in the session's scratch folder, deleted afterwards; its servers and bots used their own `instances/92`–`98` folders under `~/.local/share/nOSS/` (covered by its row above). The screen-reader checks ran as in M4.
- M9's Windows checks (`tools/endless_determinism.sh`, and `tools/net_check.py --exported`: the exported dedicated server on an endless road with an exported Linux bot and the Windows export as a bot) ran the Windows export under Wine in throwaway prefixes in temporary folders, deleted afterwards (and their `wineserver` stopped). The screen-reader checks ran as in M4; the long drive's windowed run opened a window only while it ran.
- M7's Windows traffic check (`tools/traffic_determinism.sh`) and the export check (the exported dedicated server on a highway with an exported Linux bot and the Windows export as a bot) ran the Windows export under Wine in a throwaway prefix in a temporary folder, deleted afterwards. A windowed perf run waited on sleeping monitors and was stopped; no display settings were changed.
- M5's online checks (`tools/net_check.py`, `tools/net_sim.py`) run on 127.0.0.1 with ports 47800–47900 only while they run; their logs go to `reports/net_check/` in the project (ignored by git). Fresh-client runs use a cache folder there, not `~/.local/share/nOSS/cache`.
